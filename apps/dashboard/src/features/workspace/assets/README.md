# Computer illustrations

Representative hardware photographs used decoratively in Setup & tools. Actual model, chip, memory and OS labels always come from diagnostics; images do not imply an exact model or generation. Unknown Mac desktop families retain the neutral monitor icon.

Downloaded 2026-11-06 from the manufacturers' public product pages. Product imagery and trademarks belong to their respective owners. These are product reference images, not an assertion of affiliation.

- `mac-mini.webp`: Apple Mac mini, https://www.apple.com/v/mac-mini/ab/images/overview/contrast/product_tile_mac_mini__gb0ctje8weqa_large_2x.png
- `mac-studio.webp`: Apple Mac Studio, https://www.apple.com/v/mac-mini/ab/images/overview/contrast/product_tile_mac_studio__fm2ed4r8adqq_large_2x.png
- `macbook.webp`: Apple MacBook Air, https://www.apple.com/v/macbook-air/specs/c/images/specs/13-inch/mba_13_hero__c067qisf51oy_large_2x.jpg
- `windows.webp`: Microsoft Surface Laptop, https://images.ctfassets.net/jy9s7k22hbg4/7nol3BojitE7SFBvuweyyH/d29b360d9d35c634a0a61aa0fd1f6177/Msft-Laptop-Device.png

Cropped transparent padding, removed the border-connected white background from the MacBook photo and encoded as WebP. Bundled through Vite so desktop, local dashboard and hosted demo work without remote image requests. No image is generated from CSS.
