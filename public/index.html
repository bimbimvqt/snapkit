A little setup. A lot of flow.

01
Connect your toolchain

Install Flutter, Android SDK, and Xcode on macOS. Put flutter, adb, and emulator on PATH.

02
Pick your workspace & target

Open Workspace settings, enter a Flutter project path, boot a device, then click Set target. Snapkit writes a Dart configuration in .vscode/launch.json.

03
Run your app, keep your flow

Run app starts a Dashboard-managed Flutter session. In VS Code, select “Snapkit: Active Device” and press F5 instead. Hot reload all controls sessions started here.

Physical devices must already be paired and authorized. iOS tooling requires macOS. Sample data is available with npm run demo.
